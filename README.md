# Hyprland Dotfiles

A minimal and clean Arch Linux setup with Hyprland.

## 🔧 Components
- **WM:** Hyprland
- **Bar:** Waybar
- **Terminal:** Kitty
- **Launcher:** Wofi
- **Lock Screen:** Hyprlock
- **SDDM Theme:** SilentSDDM (catppuccin-mocha)

## 🎨 Color Palette
Background: `#14141C`  
Accent: `#80A8EB`  
Secondary Text: `#9AA2C5`

## 📁 Structure
- `hypr/` – Hyprland window manager configuration
- `waybar/` – Status bar modules and styling
- `kitty/` – Terminal emulator settings
- `hyprlock/` – Screen locker appearance
- `avizo/` – Volume OSD styling
- `sddm.conf` – Display manager theme setup
